# Plan: Site Icon

Use the KitKeep app icon as the website's favicon, as the iPhone home-screen icon, and as the logo in the page header.

## Validation Commands
- `npm ci`
- `npm test`
- `npm run check`
- `npm run build`

## Decisions
- **Source:** the app repo's `docs/design/logo/kitkeep-app-icon.svg`. Copy only that one file; nothing else in the app repo is read. The maintainer supplies the file if it isn't available locally.
- **Favicon coverage:** an SVG favicon plus a 180×180 `apple-touch-icon.png`. No `favicon.ico`, no 32px PNG and no web manifest. A request to `/favicon.ico` goes to the root of `weberlance.github.io`, which this repo doesn't control, so the `<link rel="icon">` tag is what makes the favicon work.
- **Header logo:** the same app icon tile, with rounded corners, before the word "KitKeep". The mark variants (`kitkeep-mark-*-bg.svg`) are not used.
- **Metadata:** the embedded C2PA provenance record (`<metadata>` and the `xmlns:c2pa` namespace) is stripped from the site's copy, which leaves about 1.5 KB. The app repo's original isn't changed.
- **No dependency:** the PNG is rendered once on macOS and committed. It isn't made during the build.
